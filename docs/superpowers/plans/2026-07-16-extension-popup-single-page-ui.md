# 插件 Popup 单页 UI 实现计划

## 目标

将已确认的视觉原型落到正式 Plasmo popup：素材分析位于上方，当前页面分析位于下方；分析范围通过分体按钮选择，默认区域框选；设置使用独立二级视图。

## 阶段一：测试与展示模型

- 为区域/整页动态文案、默认区域范围和范围选项补充单元测试。
- 为基于现有 `lucide` 包的 React 图标组件补充静态渲染测试，确保不再使用 Emoji。
- 为单页布局补充静态结构测试，确认素材区先于页面分析区，且不再渲染 Tabs 和快速保存按钮。

## 阶段二：正式组件重构

- 新增 `PopupIcon` 与 `PageAnalysisSection`。
- 重构 Header、AssetSection、SettingsSection、StatusBanner 和 Footer。
- PopupApp 改为单页内容与独立设置视图。
- 保留 controller 中的保存能力和快捷键设置，仅移除 popup 的快速保存入口。
- 扩展中英文文案，保持功能和警告多语言。

## 阶段三：样式与交互

- 将原型的暖色视觉变量迁移到正式样式。
- 实现素材拖拽、粘贴、链接折叠、向上展开的范围菜单、独立设置页和悬浮 Toast。
- 增加键盘焦点、点击外部关闭、减少动态效果适配和内容区滚动。

## 阶段四：验证交付

- 运行 popup 相关测试、插件完整测试和 TypeScript 类型检查。
- 运行 Plasmo 生产构建并检查构建产物。
- 提交到 `develop`，不推送远程。
