# 插件框选录屏延时启动设计

## 目标

在现有框选录屏流程中增加可配置延时，让用户在真正录制开始前有时间切换页面状态或准备操作，同时确保倒计时界面不会进入录屏结果、不会消耗有效录制时长，也不会破坏当前录屏权限预热机制。

## 交互设计

- 框选完成后的紧凑工具栏增加延时图标按钮，使用 Lucide `Timer` 图标并显示当前值徽标。
- 可选值为关闭、3 秒、5 秒；默认 3 秒，并通过 `chrome.storage.sync` 记住用户上次选择。
- 点击延时按钮按“关闭 → 3 秒 → 5 秒 → 关闭”循环切换，悬浮提示和 `aria-label` 使用当前语言完整说明结果。
- 用户点击录屏后先等待录屏权限准备完成，再在框选区域中央显示大号 `3 → 2 → 1` 倒计时。
- 倒计时期间框选区域保持锁定，页面其他区域仍可操作；工具栏保留取消入口，Esc 同样可以取消。
- 倒计时结束后才启动底层 MediaRecorder、切换为录制中工具栏并从 `00:00` 开始计时。
- 重录确认后沿用本次选择的延时，再次倒计时后开始新片段；旧片段在重录确认时丢弃。

## 状态与数据流

延时值属于录屏偏好，而不是单次录屏结果。内容脚本初始化时从 `chrome.storage.sync` 读取，缺失或非法值回退为 3 秒；切换后立即写回。

首次录屏流程为：

1. 用户点击录屏，锁定本次框选区域、声音设置和延时设置。
2. 等待已预热的录屏来源就绪。
3. 延时为 0 时直接发送 `START_AREA_RECORDING`；否则进入可取消倒计时。
4. 倒计时完成且当前框选会话仍有效时，发送启动消息。
5. 收到启动成功响应后才建立录制计时器并显示录制中控件。

重录流程为：

1. 用户二次确认重录后发送重录准备命令，丢弃旧分片并让新 MediaRecorder 保持未启动状态。
2. 使用锁定的延时值执行倒计时。
3. 倒计时完成后启动新 MediaRecorder，并重置界面计时状态。

为避免重新申请 `tabCapture` 权限，重录仍复用现有输出流和裁剪画布；协议需要把“丢弃旧分片”和“开始新片段”分开，确保倒计时不会被新片段记录。

## 倒计时呈现

- 倒计时节点放在框选区域内部居中，使用 `pointer-events: none`，不阻碍页面操作。
- 数字采用暖色纸张风格的圆形浮层，每秒进行一次轻微缩放与淡入淡出。
- 倒计时节点在发送底层启动消息前移除，因此不会出现在录屏内容中。
- 启用 `prefers-reduced-motion: reduce` 时取消缩放位移，只保留数字切换。

## 取消与异常处理

- 倒计时取消使用可中止的等待控制器；取消后任何未完成异步步骤都不得继续发送启动或重录恢复消息。
- 首次录屏倒计时取消时关闭框选界面并释放已准备的录屏来源，不显示启动失败 toast。
- 重录倒计时取消时保持当前录屏会话为暂停状态，不错误恢复已丢弃的旧片段；用户可再次重录或取消整个录屏。
- 页面卸载、框选层被移除或扩展上下文失效时，统一中止倒计时并释放对应资源。
- 权限准备或底层启动失败仍使用现有多语言错误提示，并恢复可操作状态。

## 代码边界

- `extension/src/content/area-recording.ts`：延时值校验、循环切换、倒计时状态和本地化文案的纯函数。
- `extension/src/content/area-recording.test.ts`：覆盖默认值、非法值回退、循环顺序、倒计时序列和多语言文案。
- `extension/contents/inspoclip.ts`：读取与保存偏好、渲染延时按钮、协调首次录屏和重录倒计时、处理中止。
- `extension/src/background/offscreen-recording.ts` 与 `extension/src/offscreen/area-recorder.ts`：拆分重录准备和延时后的正式启动。
- `extension/src/content/styles.ts`：延时徽标、倒计时浮层、数字过渡和低动态偏好样式。
- `extension/src/content/area-toolbar-icons.ts`：增加 Lucide `Timer` 动态图标映射。

## 验证

- 单元测试覆盖延时配置、工具栏图标与文案、倒计时取消、首次启动消息顺序和重录消息顺序。
- 确认 MediaRecorder 只在倒计时完成后开始，录制计时不包含等待时间。
- 确认取消倒计时后不会延迟发送启动消息，准备资源会被释放。
- 确认重录沿用声音与延时设置，不重新获取 stream ID。
- 运行插件完整 Vitest、TypeScript 类型检查和 Plasmo 生产构建。
