# 插件框选操作栏布局与视觉优化设计

## 目标

优化框选完成后操作栏的布局、按钮语义和视觉层级，使其默认贴合框选区域右下角显示，并将所有操作按钮统一为图标按钮与自定义悬浮文字提示。

## 视觉方向

采用已确认的“紧凑 Dock”方案。操作栏保持 InspoClip 现有暖色纸张视觉，但减少文字按钮造成的宽度波动，使用紧凑单行图标、细分隔线、轻边框和克制阴影形成悬浮工具 Dock。

操作栏不引入外部图标依赖，所有图标使用风格统一的内联 SVG：1.75px 圆角描边、`currentColor` 继承状态颜色、16px 视觉尺寸。

## 布局规则

- 默认位置为框选区域外侧右下角，操作栏右边缘与框选框右边缘对齐，间距为 10px。
- 底部空间不足时，操作栏移动到框选区域外侧右上方，仍保持右边缘对齐。
- 当框选区域靠近视口左右边界时，将操作栏整体限制在 12px 的安全边距内。
- 操作栏位置计算使用真实控件尺寸；首次渲染前使用各状态的紧凑尺寸作为回退值。
- 位置箭头从居中改为靠右，与操作栏和框选框的右对齐关系一致。
- 小视口下仍保持单行图标布局，不通过文字换行增加高度。

## 框选完成状态

按钮从左至右排列：

1. 截图：选区扫描图标，普通次级按钮。
2. 开始录屏：摄像机图标，暖棕色主按钮。
3. 分隔线。
4. 标签页声音：开启时为音量图标和强调状态；关闭时为静音图标和普通状态。
5. 取消：关闭图标，使用低强调透明按钮。

标签页声音由图标按钮承担开关交互，使用 `aria-pressed` 暴露状态，不再显示文字开关。

## 录制中状态

操作栏从左至右排列：

1. 红色状态点与等宽计时文本。
2. 声音状态图标；只展示本次录制是否包含标签页声音，不允许录制中修改。
3. 分隔线。
4. 暂停/继续：根据当前状态切换暂停与播放图标及提示文字。
5. 重录：逆时针旋转图标。
6. 完成并分析：对勾图标，使用主按钮样式。

录制状态下不展示文字操作按钮，计时是唯一持续显示的文字信息。

## 重录确认状态

- 首次点击重录图标后，图标按钮切换为危险色，并在按钮上方短暂展示“再次点击确认重录”的确认气泡。
- 确认气泡不是操作按钮，不违反图标按钮规则；2.5 秒无操作后自动回到普通重录状态。
- 第二次点击执行重录，按钮进入禁用和处理中状态；图标可使用轻量旋转动画表达正在切换录制器。
- 重录完成后恢复普通状态并将计时归零；失败时恢复按钮并显示现有多语言 toast。

## 悬浮提示与可访问性

- 不使用浏览器原生 `title` 作为主要提示，避免样式和延迟不可控。
- 图标按钮统一通过 `data-tooltip` 和伪元素/共享提示层显示本地化文字。
- 提示默认位于按钮上方；当操作栏位于框选框上方时，提示可切换到按钮下方，避免遮挡选区。
- 鼠标悬浮和键盘 `:focus-visible` 均显示提示；提示不接收指针事件。
- 每个按钮提供与提示一致的 `aria-label`，状态按钮同步更新 `aria-pressed`。
- 提示文字包含具体结果，例如“完成并分析”“录制标签页声音：已开启”，避免仅使用模糊动词。

## 交互与动效

- 按钮尺寸统一为 32×32px，圆角 9px，图标视觉尺寸 16px。
- 悬浮时使用轻微背景和 `translateY(-1px)`，按下时恢复原位。
- 主按钮保持暖棕色填充；声音开启使用较轻的强调背景；取消保持低强调。
- 动效时长控制在 120–180ms，并通过 `prefers-reduced-motion` 关闭位移和旋转动画。
- 操作栏继续阻止事件穿透自身，但录屏状态下不会阻挡页面其他区域操作。

## 代码边界

- `extension/src/content/area-recording.ts`：负责右对齐定位算法、状态图标和本地化提示等纯函数。
- `extension/src/content/area-recording.test.ts`：覆盖定位回退、视口边界、图标输出、提示文案和声音状态。
- `extension/contents/inspoclip.ts`：使用纯函数渲染工具栏并维护声音、暂停和重录确认状态。
- `extension/src/content/styles.ts`：提供紧凑 Dock、图标按钮、提示气泡和动效样式。

## 测试与验收

- 定位测试验证右边缘对齐、底部不足时切换到上方，以及视口安全边距。
- 图标测试验证所有操作使用内联 SVG，不包含 emoji 或可见文字按钮。
- 文案测试验证中英文提示、暂停/继续、声音开关及重录确认状态。
- 样式测试验证图标按钮尺寸、提示的 hover/focus 展示和低动态偏好。
- 运行插件完整 Vitest、TypeScript 类型检查和 Chrome MV3 生产构建。
- 浏览器手动验收三种状态：框选完成、录制中、重录确认；同时验证上下位置切换和页面可操作性。
